Settings


updateSetting($setting, $value)

  • set a configuration setting
  • the setting name must exist in the $settings array
  • the value must be valid for the specified setting
  • supports chaining
$db->updateSetting('save_last_query_info', true); $db->updateSetting('output_errors', "An Error Occurred")->updateSetting('error_output_html', true);



Get Last Error and Connection Info


lastError()

  • return the last (most recent) error
  • note that this is NOT the error from the last query
  • will include connection errors (connection and initialization) and query errors (pre check and query itself)
$lastError = $db->lastError();


hasDbConnection()

  • return if a database connection has been made or not
$hasDbConnection = $db->hasDbConnection();



Get Last Query Info


insertId()

  • get the identifier of the last query
  • will be 0 unless the last query was a successful insert
$id = $db->insertId();


rowCount()

  • get the number of rows affected by the last query
$rowCount = $db->rowCount();


error()

  • get the error from the last query
  • note that this differs from the last error
$errorText = $db->error();


success()

  • return if the last query was successful
$isSuccess = $db->success();


duration()

  • return the duration of the last query in seconds
$durationInSeconds = $db->duration();


sql()

  • return the last SQL query
$sql = $db->sql();


binds()

  • return the PDO binds for the last query
$binds = $db->binds();



Development / Debugging


displayLastQueryInfo()

  • display information about the last query
  • data includes: raw SQL, binds, duration, errors, etc
$db->displayLastQueryInfo();


info()

  • shortcut for displayLastQuery
$db->info();


display()

  • display a value for debugging
  • displays arrays as an HTML table to make query results easier to read
  • displays other values using PHP's var_dump() function
  • note that this function is not intended for displaying data in a website or web interface; it is intended to be a quick way to view database results and other information while developing
$db->display($customers);


tables()

  • output a list of all tables in the database
$db->tables();


fields()

  • output a list of all fields in a table
$db->fields('customers');



Retrieve Data From Raw SQL


all($sql, $binds = array(), $keyField = '')

  • execute SQL and return all result rows
  • returns a 2-dimensional array, with each row as an associative key/value array
  • optionally use $keyField to use a field as the array key. * note that array keys are required and unique, so null or duplicate values may result in rows being overwritten or omitted.
$customers = $db->all('select * from customers where last_name = :last_name;', array(':last_name' => 'Jones'), 'id');


row($sql, $binds = array())

  • execute SQL and return the first result row
  • returns a 1-dimensional associative array containing the row's fields and values
$customer = $db->row('select * from customers where last_name = :last_name order by first_name limit 1;', array(':last_name' => 'Jones'));


column($sql, $binds = array(), $keyField = '', $valueField = '')

  • execute SQL and return all values from a single column
  • optionally use $keyField to use a field as the array key. * note that array keys are required and unique, so null or duplicate values may result in rows being overwritten or omitted.
  • optionally use $valueField to specify which field's values to return
$customerNames = $db->column('select id, first_name from customers where last_name = :last_name order by first_name;', array(':last_name' => 'Jones'), 'id', 'first_name');


col($sql, $binds = array(), $keyField = '', $valueField = '')

  • shortcut for the column function
$customerNames = $db->col('select id, first_name from customers where last_name = :last_name order by first_name;', array(':last_name' => 'Jones'), 'id', 'first_name');


one($sql, $binds = array(), $valueField = '')

  • shortcut for the column function
$customerNames = $db->col('select id, first_name from customers where last_name = :last_name order by first_name;', array(':last_name' => 'Jones'), 'id', 'first_name');



Modify Database (Insert, Update, Delete, Alter, etc) From Raw SQL


query($sql, $binds = array())

  • execute SQL when no result values are needed
  • generally only needed for delete or update
  • can be used for insert statements, but the insert function is usually easier
  • returns true if the query succeeds and false if it fails; success means the query executed without errors, not that it returned results or changed any rows
$db->query('delete from customers where last_name = :last_name;', array(':last_name' => 'Jones'));



Retrieve Data From Parameters (converted to SQL)


count($sql, $binds = array(), $keyField = '')

  • return the number of rows in a table
$totalCustomers = $db->count('customers');


rowById($table, $id)

  • get a row from a table using its identifier field (usually "id")
  • returns a 1-dimensional associative array containing the row's fields and values
  • uses the id_field_name setting to determine the identifier field
  • runs query "select * from [table] where id=[id]"
$customer = $db->rowById('customers', 25);


rowWhereEqual($table, $id)

  • get a row from a table where a specified field matches a value
  • runs query "select * from [table] where [field]=[value] limit 1"
$employee = $db->rowWhereEqual('employees', 'ssn', '123-45-6789');


oneById($table, $id, $field)

  • get a single value from a table using its identifier field (usually "id")
  • returns a single value from the specified field
  • uses the id_field_name setting to determine the identifier field
  • runs query "select [field] from [table] where id=[id]"
$firstName = $db->oneById('customers', 25, 'first_name');



Modify Database (Insert, Update, Delete, Alter, etc) From Parameters (converted to SQL)


insert($table, $fields)

  • insert a new row into a table
  • returns the identifier (id) of the newly inserted row
  • uses the array keys as field names and the array values as field values
$newCustomerId = $db->insert('customers', array('first_name' => 'John', 'last_name' => 'Jones'));


insertMultiple($table, $rows)

  • insert a new row into a table
  • returns true if all rows are inserted successfully and false if any query fails
  • uses the array keys as field names and the array values as field values
  • all rows must contain the same field names
  • splits the insert into multiple queries when the number of rows exceeds the max_records_per_insert_query setting
  • insert a new row into a table
$isSuccess = $db->insertMultiple('customers', array( array('first_name' => 'John', 'last_name' => 'Jones'), array('first_name' => 'Susan', 'last_name' => 'Smith') ));


insertMultipleFieldsValues($table, $fields, $dataRows)

  • insert multiple new rows into a table using a separate array of field names
  • returns true if all rows are inserted successfully and false if any query fails
  • uses $fields for the field names and $dataRows for the row values
  • all rows must contain the same number of values as the number of fields
  • pre-validates all rows before inserting, so a misformatted row prevents any rows from being inserted
  • splits the insert into multiple queries when the number of rows exceeds the max_records_per_insert_query setting
$isSuccess = $db->insertMultipleFieldsValues( 'customers', array('first_name', 'last_name'), array( array('John', 'Jones'), array('Jane', 'Smith') ) );


update($table, $values, $whereSql, $whereBinds = array())

  • update rows in a table
  • returns true if the query succeeds and false if it fails
  • uses $values to specify the fields and values to update
  • uses $whereSql to specify which rows to update
  • $whereSql is required to avoid mistakes; if all rows need to be updated, set $whereSql to "true" to match all rows.
  • optionally use $whereBinds to bind values to the $whereSql statement
$isSuccess = $db->update('customers', array('first_name' => 'John'), 'last_name = :last_name', array(':last_name' => 'Jones'));


updateById($table, $values, $id)

  • update a row in a table using its identifier field (usually "id")
  • returns true if the query succeeds and false if it fails
  • uses the id_field_name setting to determine the identifier field
$isSuccess = $db->updateById('customers', array('first_name' => 'John'), 25);


deleteById($table, $id)

  • delete a row from a table using its identifier field (usually "id")
  • returns true if the query succeeds and false if it fails
  • uses the id_field_name setting to determine the identifier (id) field
  • runs query "delete from [table] where id=[id]"
$isSuccess = $db->deleteById('customers', 25);



SQL Expression Helpers


raw($value)

  • mark a value as raw SQL instead of a value to be bound
  • raw SQL is inserted directly into the query and is not protected by PDO binding
  • only use with SQL that is known to be safe
// use SQL expression to set the current date from the database $insertValues = array( 'username' => 'bob_jones', 'signup_date' => $db->raw('CURDATE()')); $db->insert('customers', $insertValues); // today's date will be entered in the database for the signup_date of the new record. // AVOID THIS ------- // note that if the raw function is not used, the program will literally try to enter "CURDATE()" $insertValues = array( 'username' => 'bob_jones', 'signup_date' => 'CURDATE()'); $db->insert('customers', $insertValues); // the query will literally try to enter "CURDATE()" as the date. // This will NOT set the current date as intended. It will either return an error or // convert it to an empty/zero date, depending on the Database mode/settings. // AVOID THIS ------- // note that this is not needed where raw SQL is already used $sql = 'select * from customers where signup_date=:signup_date'; $binds = array(':signup_date' => $db->raw('CURDATE()')); $customersToday = $db->all($sql, $binds); // will correctly retrieve the array of customers added today (where signup_date = the current date) // since we are already in raw sql, we can simply add "CURDATE()" directly into the $sql string // this is much simpler and clearer. it will return the same results $sql = 'select * from customers where signup_date=CURDATE()'; $customersToday = $db->all($sql); // will correctly retrieve the same array of customers added today
